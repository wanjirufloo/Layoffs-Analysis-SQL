# Layoffs Analysis (SQL)

## Overview
Analyzed a dataset of 1,900+ layoff records across the United States to identify patterns in workforce reductions following COVID-19.

## Data Cleaning
The dataset was cleaned using SQL by handling missing values, removing duplicates, and standardizing inconsistent formatting.

## Analysis
Explored trends in layoffs across industries, time periods, and geographic locations.

## Key Findings
- Technology sector recorded the highest number of layoffs
- Layoffs peaked during specific months following major economic shifts
- Certain states experienced higher concentrations of layoffs

## Conclusion
The analysis highlights industry and regional patterns in workforce reductions and provides insight into post-COVID economic adjustments.
